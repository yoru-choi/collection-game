# 캐릭터 수집형 RPG 게임 - 빠른 시작 가이드

## 🚀 빠른 시작 (5분 안에!)

### 1단계: 프로젝트 설정

```bash
# 의존성 설치
npm install
```

### 2단계: 환경 변수 설정 (선택사항)

개발 모드에서는 기본값이 자동으로 적용됩니다. 백엔드 서버와 연동하려면:

```bash
# .env 파일 생성
cp .env.example .env

# .env 파일을 열어 백엔드 서버 주소 수정
# VITE_API_BASE_URL=http://localhost:8080
# VITE_WS_URL=ws://localhost:8080
```

### 3단계: 개발 서버 실행

```bash
npm run dev
```

브라우저가 자동으로 열리고 `http://localhost:3000`에서 게임이 실행됩니다!

## 🎮 게임 시작하기

### 로그인 화면

- **Guest Login (Dev)** 버튼을 클릭하여 즉시 게임을 시작할 수 있습니다
- 실제 회원가입/로그인 기능은 백엔드 연동 후 사용 가능합니다

### 메인 로비

게스트 로그인 후 메인 로비에서 다음 메뉴를 이용할 수 있습니다:

- **🎲 Summon**: 캐릭터 소환 (가챠)
- **👥 Characters**: 보유 캐릭터 목록 및 관리
- **🏰 Dungeon**: 던전 선택 및 전투
- **⚔️ Arena**: PvP 아레나 (개발 중)
- **🛡️ Guild**: 길드 시스템 (개발 중)
- **🛒 Shop**: 상점 (개발 중)
- **🎒 Inventory**: 인벤토리 및 룬 관리 (개발 중)

## 💎 개발자 모드 기능

### Mock 데이터

게임을 처음 실행하면 자동으로 테스트용 플레이어 데이터가 생성됩니다:

- 레벨: 10
- 크리스탈: 1,000 💎
- 골드: 50,000 🪙
- 에너지: 80/100 ⚡

### 게스트 로그인

인증 없이 즉시 게임을 테스트할 수 있습니다.

### 브라우저 저장소

게임 데이터는 `localStorage`에 저장됩니다. 초기화하려면:

```javascript
// 브라우저 개발자 도구 콘솔에서 실행
localStorage.clear();
location.reload();
```

## 🎯 주요 기능 테스트

### 1. 캐릭터 소환 테스트

1. 로비에서 **Summon** 클릭
2. **Normal Summon** 또는 **Premium Summon** 선택
3. 소환 애니메이션 후 결과 확인
4. **Confirm** 버튼으로 캐릭터 획득 완료

### 2. 캐릭터 관리 테스트

1. 로비에서 **Characters** 클릭
2. 보유 캐릭터 목록 확인
3. 캐릭터 카드 클릭하여 상세 정보 확인
4. 레벨업, 진화, 룬 관리 버튼 (기능 개발 중)

### 3. 던전 & 전투 테스트

1. 로비에서 **Dungeon** 클릭
2. 던전 카테고리 선택 (Story, Element 등)
3. 전투 화면으로 이동
4. Auto, Speed, Pause 버튼 테스트

## 🐛 문제 해결

### 게임이 로드되지 않음

```bash
# 캐시 정리 및 재설치
rm -rf node_modules package-lock.json
npm install
npm run dev
```

### 화면이 검게만 보임

- 브라우저 콘솔(F12)에서 에러 메시지 확인
- `localStorage.clear()` 후 새로고침

### 백엔드 연동 에러

- `.env` 파일의 API URL 확인
- 백엔드 서버가 실행 중인지 확인
- CORS 설정 확인
