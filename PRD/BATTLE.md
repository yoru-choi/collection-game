# 전투 시스템 PRD (Product Requirements Document)

## 1. 전투 시스템 개요

### 1.1 전투 방식
**ATB(Attack Bar) 기반 실시간 턴제 전투**를 채택하여, 턴제 전략성과 실시간 흐름을 결합한다.

### 1.2 핵심 메커니즘
- **ATB 게이지**: 각 소환수의 속도(SPD) 스탯에 따라 ATB가 실시간으로 증가
- **행동 순서**: ATB가 100% 채워진 소환수부터 행동 가능
- **오토/수동 모드**: 플레이어는 전투 중 언제든지 Auto ON/OFF 전환 가능
- **파티 구성**: 최대 4명까지 구성 가능

## 2. 전투 시스템 상세

### 2.1 ATB 기반 전투 시스템

#### 2.1.1 속도(SPD) 스탯
- 각 소환수(몬스터)는 **속도(SPD)** 스탯을 보유
- SPD 값이 높을수록 ATB가 빠르게 증가
- ATB는 전투 중 실시간으로 증가하며, 0%에서 100%까지 채워짐

#### 2.1.2 행동 순서 결정
- ATB가 **100% 채워진 소환수**부터 행동 가능
- 여러 소환수의 게이지가 동시에 찬 경우, **SPD 스탯**이 높은 순서로 행동
- 행동을 완료한 소환수는 ATB가 0%로 초기화되고 다시 증가 시작

#### 2.1.3 ATB 증가 공식 (예시)
```
ATB 증가량 (per tick) = SPD / 100
```
- Tick 주기: 100ms (1초당 10 tick)
- SPD 100인 소환수는 약 10초마다 행동
- SPD 200인 소환수는 약 5초마다 행동

### 2.2 오토 전투 & 수동 전투 모드

#### 2.2.1 아군 (플레이어 파티)

**오토 모드 (Auto ON)**
- AI가 자동으로 스킬 선택 및 공격 대상 지정
- 게이지가 가득 찬 소환수가 자동으로 행동
- 배속 기능: x1, x2 지원 (오토 모드 최대 x2)
  - x1: 기본 속도
  - x2: 게이지 증가 속도 2배, 애니메이션 2배속

**수동 모드 (Auto OFF)**
- 게이지가 가득 찬 아군 소환수의 턴이 되면 **전투 일시 정지**
- 플레이어가 직접 스킬 선택 및 공격 대상 지정
- 행동을 선택하면 다음 턴으로 진행
- 수동 모드에서도 배속 설정은 유지 (다음 턴까지의 게이지 증가 속도)

**모드 전환**
- 전투 중 언제든지 Auto ON/OFF 토글 가능
- Auto 버튼 UI를 통해 쉽게 전환
- 모드 전환 시 현재 진행 중인 행동은 영향 받지 않음

#### 2.2.2 적군 (AI 파티)
- 무조건 **오토 모드**로 동작
- 게이지가 가득 찬 적 소환수가 자동으로 행동
- 플레이어는 제어 불가능
- AI 행동 패턴:
  - 기본 공격: 랜덤 대상 또는 HP가 낮은 대상 우선
  - 스킬 사용: 사용 가능한 스킬 중 우선순위가 높은 스킬부터 사용
  - 힐/버프: 아군이 필요한 상황에 사용

### 2.3 스킬 시스템

#### 2.3.1 스킬 구성
각 캐릭터는 **4개의 스킬**을 보유:
1. **스킬 1 (기본 공격)**: 쿨타임 없음, 게이지만 소모
2. **스킬 2**: 쿨타임 2턴
3. **스킬 3**: 쿨타임 3턴
4. **스킬 4 (궁극기)**: 쿨타임 5턴

#### 2.3.2 쿨타임 시스템
- 쿨타임은 **해당 소환수의 턴 기준**으로 계산
- 스킬 사용 후 쿨타임이 설정되고, 자신의 턴마다 1씩 감소
- 쿨타임이 0이 되면 다시 사용 가능

#### 2.3.3 스킬 효과
**직접 데미지**
- 단일 대상 공격
- 광역 공격 (전체 또는 다수)
- 랜덤 대상 공격 (3회 등)

**버프 (아군 강화)**
- 공격력 증가
- 방어력 증가
- 속도 증가
- 치명타율 증가
- 회복 (HP 회복)

**디버프 (적 약화)**
- 공격력 감소
- 방어력 감소
- 속도 감소
- 명중률 감소

**상태이상**
- **스턴**: 1턴 행동 불가 (턴 도래 시 행동 스킵)
- **침묵**: 액티브 스킬 사용 불가 (기본 공격만 가능)
- **도발**: 도발한 대상만 기본 공격 (스킬 1)으로 공격
- **수면**: 1~2턴 행동 불가
  - 피격 시 50% 확률로 기상
  - 기상에 성공하면 해당 턴에 즉시 행동 가능
- **얼음**: 1턴 행동 불가 (턴 도래 시 행동 스킵)
- **독**: 턴마다 HP 감소 (최대 HP의 %)
- **화상**: 턴마다 HP 감소 (고정 수치)
- **방어력 감소**: 받는 피해 증가
- **공격력 감소**: 주는 피해 감소
- **속도 감소**: ATB 증가 속도 감소
- **글랜싱**: 치명타 불가 + 데미지 감소 + 디버프 부여 확률 감소

**버프**
- **공격력 증가**: 주는 피해 증가
- **방어력 증가**: 받는 피해 감소
- **속도 증가**: ATB 증가 속도 증가
- **면역**: 디버프 및 상태이상 무효
- **무적**: 피해 무효 (고정 피해 제외)
- **보호막**: 보호막 HP가 소진될 때까지 피해 흡수
- **버티기**: 치명타 피해를 받아도 HP 1 유지 (1회)

#### 2.3.4 턴/쿨타임 규칙
- 기본 공격(스킬 1)은 쿨타임 없음
- 스킬 쿨타임은 **해당 소환수의 턴 기준**으로 1씩 감소
- 스킬 사용은 ATB와 무관하며, 행동 후 ATB는 0%로 초기화
- **추가 턴**: ATB 충전 없이 즉시 다음 행동 수행 (쿨타임은 정상 감소)
- **반격/협동 공격**: 특정 조건 또는 스킬 효과로 발생
- **ATB 조작**: 스킬로 아군 ATB 증가, 적군 ATB 감소 가능

### 2.4 파티 구성

#### 2.4.1 파티 편성
- **최대 4명**까지 파티 구성
- 각 소환수는 고유의 속도(SPD) 스탯 보유
- 파티 슬롯은 고정 (1번, 2번, 3번, 4번)
- 대표 캐릭터(리더)는 1번 슬롯에 배치

#### 2.4.2 파티 시너지 스킬 존재
- 리더 스킬: 파티 전체에 버프 제공
- 속성 보너스: 동일 속성 3개 이상 시 스탯 증가
- 클래스 보너스: 클래스 조합에 따른 추가 효과

### 2.5 전투 상태 전이 (MVP)
전투 진행을 상태로 분리해 클라이언트/서버 동작을 명확히 한다.

**상태 목록**
- **Ready**: 전투 로딩, 파티/웨이브 데이터 세팅
- **InWave**: ATB 증가 및 행동 처리
- **ActionSelect**: 수동 모드에서 아군 행동 대기
- **Animating**: 스킬/피격 애니메이션 재생
- **WaveClear**: 웨이브 종료 연출
- **BattleEnd**: 승패 확정

**전이 규칙**
1. Ready → InWave
2. InWave → ActionSelect (수동 모드에서 아군 턴 도래 시)
3. ActionSelect → Animating (스킬/대상 선택 완료)
4. Animating → InWave (피해/상태 적용 후)
5. InWave → WaveClear (현재 웨이브 적 전멸)
6. WaveClear → InWave (다음 웨이브 존재)
7. WaveClear → BattleEnd (최종 웨이브 클리어)

### 2.6 전투 중단/포기 규칙
- **일시정지**: 메뉴에서 일시정지 가능, ATB 증가 정지
- **포기**: 포기 시 즉시 BattleEnd(패배) 처리
- **연결 끊김**: 클라이언트 재접속 시 마지막 전투 상태 복구 (MVP는 재입장 금지 가능)

### 2.7 보상/결과 반영 흐름
- BattleEnd에서 승패 확정
- 승리 시 보상 계산 → Result 화면 → RewardClaim 확정
- 패배 시 보상 없음, 재도전/로비 복귀 선택
- 보상 확정은 서버 트랜잭션으로 처리

### 3.2 UI 구성 요소

#### 3.2.1 상단 정보 바
- **턴 정보**: 현재 행동 중인 캐릭터 표시
- **웨이브**: 현재 웨이브 / 전체 웨이브 (예: 1/4)
- **배속 버튼**: x1, x2 토글 (오토 모드 최대 x2)
- **메뉴 버튼**: 일시정지, 설정, 포기

#### 3.2.2 전투 필드
**적군 영역 (상단)**
- 적 소환수 4개 배치 (왼쪽부터 1~4번)
- 각 소환수마다 HP 바, 버프/디버프 아이콘, ATB 게이지 표시
- 게이지가 가득 찬 적은 강조 표시 (빛나는 효과)

**아군 영역 (하단)**
- 아군 소환수 4개 배치 (왼쪽부터 1~4번)
- 각 소환수마다 HP 바, 버프/디버프 아이콘, ATB 게이지 표시
- 게이지가 가득 찬 아군은 강조 표시 + 수동 모드 시 선택 대기 상태

#### 3.2.3 하단 스킬 패널
**오토 모드 (Auto ON) 상태**
- Auto 버튼: 활성화 표시 (밝은 색상)
- 스킬 버튼: 비활성화 (투명도 50%)

**수동 모드 (Auto OFF) 상태**
- Auto 버튼: 비활성화 표시 (어두운 색상)
- 스킬 버튼: 활성화
  - 사용 가능한 스킬: 밝게 표시
  - 쿨타임 중인 스킬: 어둡게 표시 + 남은 쿨타임 숫자
- 스킬 선택 후 → 대상 선택 모드로 전환 (적 캐릭터 클릭)

#### 3.2.4 게이지 표시
- **게이지 바**: 각 소환수 아래에 표시
- **색상**:
  - 0~50%: 노란색
  - 51~99%: 주황색
  - 100%: 녹색 + 깜빡임 효과
- **수치**: 게이지 % 표시 (옵션)

### 3.3 전투 플로우

#### 3.3.1 전투 시작
1. 던전 입장 → 로딩 화면
2. 전투 화면 진입 + 웨이브 1 안내
  - 일반 던전은 총 4 웨이브 구성
  - 웨이브당 적은 1~4기까지 출현 가능
3. 적군 출현 애니메이션
4. 게이지 증가 시작

#### 3.3.2 전투 진행 (오토 모드)
1. 아군/적군 모두 게이지 자동 증가
2. 게이지 100% 도달 시 즉시 행동
3. AI가 스킬 선택 및 대상 지정
4. 스킬 애니메이션 재생
5. 데미지 계산 및 HP 감소
6. 게이지 초기화 후 다시 증가

#### 3.3.3 전투 진행 (수동 모드)
1. 아군 게이지 100% 도달 시 **일시 정지**
2. 스킬 패널 활성화 + 선택 대기
3. 플레이어가 스킬 선택
4. 대상 선택 모드 진입 (적 캐릭터 클릭)
5. 스킬 애니메이션 재생
6. 데미지 계산 및 HP 감소
7. 일시 정지 해제 + 게이지 증가 재개

#### 3.3.4 웨이브 클리어
1. 모든 적 HP 0 → 웨이브 클리어 연출
2. 다음 웨이브가 있으면 새로운 적 출현
3. 아군 게이지는 유지 (초기화 안 함)
4. 마지막 웨이브 클리어 시 전투 종료

#### 3.3.5 전투 종료
**승리**
- 승리 연출 (불꽃놀이, 환호 등)
- 보상 화면으로 전환
- 획득 아이템, 골드, 경험치 표시

**패배**
- 패배 연출
- 재도전 또는 로비 복귀 선택

### 3.4 애니메이션 및 이펙트

#### 3.4.1 스킬 애니메이션
- 각 스킬마다 고유 이펙트
- 단일 공격: 대상에게 직선으로 이펙트
- 광역 공격: 범위 표시 + 전체 이펙트
- 버프/디버프: 아이콘 + 파티클 효과

#### 3.4.2 히트 이펙트
- 데미지 숫자 표시 (노란색: 일반, 빨간색: 치명타)
- 화면 흔들림 (강력한 공격 시)
- HP 바 감소 애니메이션

#### 3.4.3 상태 이상 이펙트
- 스턴: 별 아이콘 + 어지러운 효과
- 독: 보라색 독 구름
- 화상: 불꽃 파티클
- 얼음: 얼음 결정 효과

## 4. 전투 관련 API

### 4.1 전투 시작
```
POST /api/v1/dungeons/:id/battle
```

**Request Body**
```json
{
  "party": [1, 2, 3, 4]  // 캐릭터 ID 배열
}
```

**Response**
```json
{
  "battle_id": "battle_123",
  "dungeon_id": 1,
  "wave_count": 4,
  "enemies": [
    {
      "position": 1,
      "monster_id": 101,
      "name": "고블린",
      "level": 5,
      "hp": 1000,
      "atk": 100,
      "def": 50,
      "spd": 80
    }
  ],
  "allies": [
    {
      "position": 1,
      "character_id": 1,
      "name": "화염 기사",
      "level": 10,
      "hp": 2000,
      "atk": 200,
      "def": 100,
      "spd": 90
    }
  ]
}
```

### 4.2 전투 액션
```
POST /api/v1/battle/:id/action
```

**Request Body (수동 모드)**
```json
{
  "character_id": 1,
  "skill_id": 2,
  "target_position": 1  // 적 포지션
}
```

**Response**
```json
{
  "action_result": {
```

## 5. 전투 밸런스

### 5.1 속도(SPD) 스탯 기준
| SPD | 행동 주기 (초) | 설명 |
|-----------|---------------|------|
| 50        | ~20s          | 매우 느림 (탱커) |
| 75        | ~13s          | 느림 |
| 100       | ~10s          | 보통 |
| 125       | ~8s           | 빠름 (딜러) |
| 150       | ~6.5s         | 매우 빠름 (암살자) |
| 200       | ~5s           | 초고속 (버프 전용) |

### 5.2 스킬 밸런스
- **기본 공격 (스킬 1)**: 데미지 배율 100%
- **스킬 2**: 데미지 배율 150% ~ 200%, 쿨타임 2턴
- **스킬 3**: 데미지 배율 250% ~ 300%, 쿨타임 3턴
- **궁극기 (스킬 4)**: 데미지 배율 400% ~ 500%, 쿨타임 5턴

### 5.3 스테이지 난이도 조정
| 난이도 | 적 HP | 적 ATK | 적 DEF | 보상 배율 |
|--------|-------|--------|--------|----------|
| Normal | 100%  | 100%   | 100%   | 1.0x     |
| Hard   | 200%  | 150%   | 150%   | 2.0x     |
| Hell   | 400%  | 200%   | 200%   | 3.5x     |

## 7. 기술적 고려사항
