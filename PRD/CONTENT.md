# 게임 콘텐츠 PRD (Product Requirements Document)

## 1. 개요
스토리 던전과 주요 PvE 콘텐츠, 추후 확장 콘텐츠를 정의한다.

### 1.1 콘텐츠 진행 흐름 (MVP)
1. **던전 선택**: 챕터/스테이지/난이도 선택
2. **에너지 확인**: 부족 시 에너지 구매 또는 다른 콘텐츠 안내
3. **전투 진행**: [BATTLE.md](./BATTLE.md) 흐름 준수
4. **클리어/실패**: 결과 화면에서 보상 요약
5. **보상 확정**: 보상 수령 → 성장/소환/다음 스테이지로 이동

---

## 2. PvE 콘텐츠

### 2.1 스토리 던전
- 챕터별 스테이지 구성
- 난이도: Normal, Hard, Hell
- 보상: 크리스탈, 골드, 캐릭터 조각

**해금 규칙 (MVP)**
- 동일 난이도에서 이전 스테이지 클리어 시 다음 스테이지 해금
- 챕터 보스 클리어 시 다음 챕터 해금
- 난이도 해금은 Normal 챕터 클리어 후 Hard, Hard 클리어 후 Hell
